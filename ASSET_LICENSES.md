# Asset licenses

## Approved Quaternius / Godot Asset Store packs

The active 3D village hub uses only approved CC0 Quaternius packs from Godot Asset Store.

### Medieval Village MegaKit

- Author: Quaternius
- Source: `https://store.godotengine.org/asset/quaternius/medieval-village-megakit/`
- License: CC0 1.0 Universal
- Use: village buildings, modular medieval environment pieces, inn/blacksmith/dungeon style objects.

### Fantasy Props MegaKit

- Author: Quaternius
- Source: `https://store.godotengine.org/asset/quaternius/fantasy-props-megakit/`
- License: CC0 1.0 Universal
- Use: crates, barrels, market/blacksmith props, weapons, furniture, chests, potions, and other medieval props.

### Stylized Nature MegaKit

- Author: Quaternius
- Source: `https://store.godotengine.org/asset/quaternius/stylized-nature-megakit/`
- License: CC0 1.0 Universal
- Use: trees, rocks, bushes, plants, grass, and general stylized nature dressing.

The repository does not manually commit these large asset zips. The approved installer downloads them during build, extracts a curated subset, and publishes the generated files into the build artifact.

## Legacy Kenney Hexagon Pack

- Source package: `kenney-hexagon-pack`
- Original author: Kenney
- License: Creative Commons Zero 1.0 Universal / CC0 1.0
- Usage: legacy sprite prototype only. It is no longer the active visual direction.

## Notes

Do not add paid, unknown, AI-generated, or unclear-license assets directly to the repository. Prefer CC0, MIT, Apache-2.0, or assets with explicit commercial redistribution rights.
