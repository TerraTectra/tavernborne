# Personality simulation foundation

## Scope of the first playable laboratory

The first phase deliberately excludes the dungeon, combat, procedural expeditions, god creation and a large settlement.

The playable space is a small wagon-home for one fixed god and up to five children. Development begins with three children because this is the smallest group that can produce asymmetric relationships, rivalry, alliances and third-party reactions.

The prototype is successful when the same general event produces different believable consequences for different children and those consequences change later decisions.

## Core loop

```text
world event
  -> personal perception
  -> emotions and memories
  -> psyche and relationships
  -> needs, goals and context
  -> action evaluation
  -> independent decision
  -> visible action
  -> new world event
  -> long-term personality change
```

This is a graph with feedback loops, not a linear event script and not a single mood meter.

## Simulation layers

### Traits

Slow-changing dispositions. Values are continuous rather than boolean labels. A child can be kind, proud, friendly and cruel at the same time because each trait matters in a different context.

Initial dimensions:

- kindness / cruelty
- pride
- friendliness
- honesty
- patience
- curiosity
- discipline
- courage / caution
- impulsiveness
- empathy
- independence
- approval seeking
- trustfulness
- vengefulness
- ambition
- loyalty

### Emotions

Multiple emotions can coexist. Each emotion has intensity and should later gain a source, object, duration and decay curve.

Initial dimensions include joy, sadness, anxiety, anger, irritation, guilt, shame, fear, hope, interest, loneliness, inspiration, affection and envy.

### Psyche

Longer-lived state that changes more slowly than emotion:

- stress
- confidence
- security
- grief
- burnout
- resilience

### Needs

Needs create pressure but never become hard commands. A disciplined or ambitious child can continue working while tired; a frightened child can still act because loyalty outweighs fear.

Initial needs:

- hunger
- fatigue
- safety
- social contact
- solitude
- recognition
- growth
- belonging

### Relationships

Relationships are directional and multidimensional. A can trust B while B distrusts A. A child can love, fear and resent the same person.

Initial dimensions:

- liking
- trust
- respect
- closeness
- fear
- resentment
- envy
- attraction
- debt
- rivalry

### Memories

A memory stores the event, participants, emotional valence, importance and tags. It is not only journal text. It is data that later changes event perception and decision scoring.

Planned extensions:

- separate objective event from subjective interpretation
- semantic links to people, places, objects and event types
- recollection triggers
- reinforcement when recalled
- gradual forgetting
- trauma and belief formation

### Goals

Goals allow a child to act against temporary needs and emotions. They are the bridge between personality and purposeful behaviour.

The first version uses manually seeded goals. Later they will emerge from biography, desires, skills, relationships and events.

## Decision model

Every available action receives a utility score. The score is composed from explainable contributions:

```text
utility(action) =
  needs
  + traits
  + emotions
  + psyche
  + relationships
  + goals
  + memories
  + environmental opportunities
  + small deterministic variation
```

The engine stores the strongest reasons for every evaluated action. This explanation is required for development and balancing; otherwise emergent behaviour becomes impossible to debug.

The player will not see exact coefficients in the final game. The laboratory intentionally exposes them.

## Current laboratory

The first implementation contains:

- one fixed god, Aster
- three seeded children with conflicting personalities
- multidimensional traits, emotions, needs, psyche and relationships
- memories generated by events
- event reactions modified by personality
- autonomous utility-based decisions
- a journal of events and decisions
- a graph-like inspector for the selected child
- manual test events for praise, help, cooperation, conflict, insult, failure, injury and loss

## Next milestones

1. Separate objective event facts from personal interpretation.
2. Add target-specific emotions and emotion sources.
3. Make memories influence perception and action scoring.
4. Add relationship-driven autonomous social events.
5. Add gradual trait drift caused by repeated behaviour and strong memories.
6. Add daily schedules and interactable wagon zones.
7. Save deterministic simulation snapshots for regression tests.
8. Introduce the fourth and fifth child only after three-person dynamics remain readable.
