# RTS camp view

The default browser screen is now a top-down observation layer for the starter wagon.

## Prototype scope

- fixed god Aster;
- three autonomous children;
- functional zones for sleep, food, training, reading, work and solitude;
- movement driven by the personality simulation's selected action;
- time controls and autoplay;
- manual test events for praise, conflict, injury and loss;
- selected-child panel with mood, psyche, traits and decision reasons;
- family journal;
- previous personality laboratory and 3D village remain available as secondary views.

The player observes and influences conditions but does not directly command the children.
